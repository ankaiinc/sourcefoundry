# SourceFoundry public agent service v0 (superseded)

SourceFoundry is the public and technical product name. Existing API identifiers remain compatible.

This draft was superseded on 2026-08-25 after reviewing SourceFoundry's founding
conversation, architecture note, and initial implementation boundary.

The canonical proposal is [SourceFoundry public source supply v0](public-source-supply-v0.md).

The correction is material: SourceFoundry exists to operate continuous,
reusable source supply for consuming products. It is not an on-demand research
or answer-generation service. API and MCP are interfaces for configuring source
feeds and retrieving neutral candidate inventory while each consuming product
retains its own interpretation, ranking, publication, and customer experience.
