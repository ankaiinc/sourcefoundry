# Support

SourceFoundry is a public-beta open-source project.

- Setup or usage questions: open a [GitHub Discussion](https://github.com/ankaiinc/sourcefoundry/discussions).
- Reproducible bugs: open a [bug report](https://github.com/ankaiinc/sourcefoundry/issues/new/choose).
- Provider or contract proposals: open a feature request before implementing the change.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting. Do not open a public issue.

Support is best-effort. Include the SourceFoundry release, deployment method, relevant health output, and redacted reproduction steps. Never include tokens, provider keys, private source URLs, or customer data.
